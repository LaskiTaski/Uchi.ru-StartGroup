# Инструменты проекта

Запускать из корня проекта.

## Проверка данных

```
python3 tools/validate.py
```

Проверяет манифест, структуру блоков, уникальность якорей, перекрёстные
ссылки и синтаксис примеров кода. Возвращает код 1 при ошибках —
можно вешать на pre-commit и CI.

## Сборка поискового индекса

```
python3 tools/build_search_index.py
```

Собирает `data/search-index.json`. **Запускать после каждой правки
контента**, иначе поиск будет искать по старым данным.

## Сквозной тест интерфейса

```
npm install jsdom      # один раз
node tools/e2e.mjs
```

Прогоняет навигацию, меню, якоря, поиск, защищённый раздел
и дедупликацию запросов. Возвращает код 1 при падении.

## Типовой порядок перед коммитом

```
python3 tools/validate.py && python3 tools/build_search_index.py && node tools/e2e.mjs
```
